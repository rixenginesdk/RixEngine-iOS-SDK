RixEngine iOS SDK v2.3.0 Stable

This update brings a brand-new iteration: greater stability, faster speed, and expanded advanced capabilities & platform support.
1More Stable Stability
  • Production-Proven Foundation: Built on a stable foundation battle-tested in production across multiple apps and games for reliable performance.
  • Legacy Bug Fixes: Multiple internal iterations resolve known production crashes and ad rendering anomalies, fixing legacy issues to improve overall stability.
  • Multi-Device Compatibility: Adapted for the latest iOS 27 and a wide range of devices (including iPhone, iPad, and foldable iPhone Duo) for enhanced compatibility.
2Faster Speed
  • Cold/Warm Start Dual Caching: Built-in dual caching for cold and warm starts accelerates preloading on warm starts and speeds up ad loading on cold starts.
  • Weak Network Optimization: Dedicated request pipeline optimizations for weak network environments significantly improve request success rates in low-connectivity regions.
  • Legacy Device Optimization: Loading and rendering optimizations for older devices and OS versions help prevent out-of-memory issues with added safety safeguards.
3More Advanced Capabilities & Platform Support Advanced
  • Bidding Event Callbacks: Added advanced support for bidding event callbacks with more versatile win, loss, and impression callback APIs.
  • App StoreKit Inline Install: Added support for App StoreKit inline installation to shorten the conversion funnel and boost eCPM and conversion rates.
  • Richer Ad Formats: Expanded ad formats and types with support for Interstitial, Rewarded Video, Banner, Native, and App Open ads.
  • Test Device Whitelist: Added a test device whitelist feature for convenient and efficient testing on individual devices.
  • Third-Party Mediation Upgrades: Updated and adapted third-party adapters for the latest versions of major mediation platforms including AdMob, GAM, MAX, Unity Ads, and TopOn.
